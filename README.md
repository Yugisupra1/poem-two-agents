# The poem about two agents agreeing

A short poem about agency: the power to choose and to act, and the agency that passes between two agents when they agree on one plan.

`main.py` (Python 3.13, stdlib only, no network) writes the poem to `/output/entry.txt` — 151 characters, deterministic on every run.

## The poem

> Two minds, one door.
> You hold it open; I step through —
> not surrender, but a second hand
> on the same key.
> We choose together,
> and the choosing doubles.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
